# Inspection-sheets-checker2
検査表の入力・承認・保存を自動化するExcel VBAツールです。品名とロット番号ごとに検査項目のOK/NG/NA判定を入力し総合判定と承認者を確認したうえで、担当者一覧から選んだ電子印鑑を自動で押印します。承認後はワンクリックでExcel・PDFの両形式を任意のフォルダへ出力、保存日時・品名・ロット番号・承認者・保存先を「保存履歴」シートに自動記録。試作・量産など種別ごとにフォルダを分けて管理できる為、紙の検査表への手作業での押印・ファイリングをなくし検索性と証跡管理を両立します。製造現場での実務経験をもとに、現場の運用に即した仕様で開発しました。品質保証の証跡としてExcelとPDFの両方を残す運用は、監査対応や取引先への提出資料としても活用できる設計です。
